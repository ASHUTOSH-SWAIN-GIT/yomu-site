# yomu-site

The website for [Yomu](https://github.com/ASHUTOSH-SWAIN-GIT/Yomu).

```bash
npm install
npm run dev     # local preview
npm run build   # static site in dist/
```

Screenshots in `public/shots/` are the real app in Yomu Light and Yomu Dark; the page shows the pair that matches its theme.
